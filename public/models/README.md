# Models

Put 3D models exported from Blender here as `.glb` files
(File → Export → glTF 2.0, format "glTF Binary").

If a file named `player.glb` exists here, the game uses it as the player
character instead of the default capsule. Keep the model about 1.8 units
tall with its feet at the origin (Blender's default unit is 1 m = 1 unit).
